## Context

Le dépôt `D:\projets\Programmation\lets-ple` ne contient aujourd'hui qu'un document de design
(`docs/superpowers/specs/2026-07-28-lets-ple-cryptogramme-design.md`) et un dossier `.idea` généré
par WebStorm. Aucun code.

Ce plan construit **Let's Plé**, un portail de jeux de langue française en PWA, et son premier jeu :
un **cryptogramme** où chaque lettre d'une citation est remplacée par un nombre. Le joueur pioche des
cartes-lettres dans une main limitée à cinq, en pose une sur la case de son choix, et dispose de
trois erreurs.

L'enjeu de conception principal est que **toutes les règles vivent dans un moteur pur sans Angular**.
C'est ce qui rend le jeu testable en millisecondes, permet de simuler des parties pour l'équilibrage,
et garantit qu'aucune position insoluble n'existe. L'interface n'est qu'une façade au-dessus.

Le plan est ordonné pour que le moteur soit jouable et prouvé correct **avant** qu'une seule ligne
d'interface ne soit écrite.

**Livrable final :** un jeu complet, jouable hors ligne, déployé sur GitHub Pages.

## Global Constraints

Ces contraintes s'appliquent à **toutes** les tâches, valeurs reprises telles quelles du spec.

- **Node 24 LTS** (≥ 24.15.0) — Angular 22 refuse de s'installer en dessous. Poste actuellement en 22.12.0.

- **Storybook 10.5.5** (`zone.js` y est une peer *optionnelle* : compatible zoneless).
- `projects/` scindé en **`apps/`**, **`libs/`**, **`games/`**. `newProjectRoot` étant une valeur

- **Nom affiché : `Let's Plé`**. Slug/package/dépôt : `lets-ple`. Sous-domaine : `letsple`.
- **Français uniquement**, mais aucun texte d'interface en dur dans un template : tout passe par les
  dictionnaires JSON. Chaque citation porte un champ `lang`.
- Règles de jeu, valeurs exactes : main de **5** cartes max, **3** erreurs, **2 à 3** correspondances

- **Aucune dépendance Angular dans `domain/`.** Contrainte vérifiée par un test automatisé (Tâche 10).
- Commits fréquents, un par tâche au minimum, messages en français.

```ts
/** Hache une chaîne en entier 32 bits (xfnv1a). */
function hashSeed(seed: string): number {
  let h = 2166136261;
  for (let i = 0; i < seed.length; i++) {
    h ^= seed.charCodeAt(i);
    h = Math.imul(h, 16777619);
  }
  return h >>> 0;
}

/** Générateur mulberry32 : rapide, déterministe, suffisant pour du jeu. */
export function createRng(seed: string): () => number {
  let state = hashSeed(seed);
  return () => {
    state = (state + 0x6d2b79f5) >>> 0;
    let t = state;
    t = Math.imul(t ^ (t >>> 15), t | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

/** Fisher-Yates sur une copie. */
export function shuffle<T>(items: readonly T[], rng: () => number): T[] {
  const result = [...items];
  for (let i = result.length - 1; i > 0; i--) {
    const j = Math.floor(rng() * (i + 1));
    [result[i], result[j]] = [result[j], result[i]];
  }
  return result;
}
```

permettra à l'affichage de restituer l'accent exact.

```ts
import type { Sym, AccentMode } from './types';

const VOWELS = new Set(['A','À','Â','Ä','E','É','È','Ê','Ë','I','Î','Ï','O','Ô','Ö','U','Ù','Û','Ü','Y','Ÿ']);

/** Retire les diacritiques : 'É' → 'E', 'Ç' → 'C'. */
function stripAccent(char: string): string {
  return char.normalize('NFD').replace(/\p{Diacritic}/gu, '');
}

export function toSymbols(text: string, mode: AccentMode): (Sym | null)[] {
  return [...text].map((char) => {
    const upper = char.toUpperCase();
    const base = stripAccent(upper);
    if (!/^[A-Z]$/.test(base)) return null;      // espace, ponctuation, apostrophe, chiffre
    return mode === 'distinct' ? upper : base;
  });
}

export function isVowel(sym: Sym): boolean {
  return VOWELS.has(sym);
}

export function distinctSymbols(symbols: readonly (Sym | null)[]): Sym[] {
  const seen = new Set<Sym>();
  const result: Sym[] = [];
  for (const sym of symbols) {
    if (sym !== null && !seen.has(sym)) {
      seen.add(sym);
      result.push(sym);
    }
  }
  return result;
}

export function symbolCounts(symbols: readonly (Sym | null)[]): Map<Sym, number> {
  const counts = new Map<Sym, number>();
  for (const sym of symbols) {
    if (sym !== null) counts.set(sym, (counts.get(sym) ?? 0) + 1);
  }
  return counts;
}
```

Note : `toSymbols` itère avec `[...text]` (par point de code) et non par index, pour ne pas couper
les caractères composés. Vérifier au passage que le test « conserve la longueur » passe bien — si
une citation contient un caractère hors BMP, il compterait pour un seul symbole ici mais deux en
`.length`. Aucun corpus français ne devrait en contenir ; si le test échoue, c'est le signe d'un
caractère exotique à nettoyer dans le corpus.

```ts
import type { Sym } from './types';
import { shuffle } from './rng';

export function buildCipher(symbols: readonly Sym[], rng: () => number): Map<Sym, number> {
  const codes = shuffle(
    Array.from({ length: symbols.length }, (_, i) => i + 1),
    rng,
  );
  return new Map(symbols.map((sym, i) => [sym, codes[i]]));
}
```

### Tâche 6 : Correspondances offertes

**Fichiers :** Créer `givens.ts` — Test : `givens.spec.ts`

**Interfaces :**
- *Consomme :* `Sym`, `isVowel`, `symbolCounts` (Tâche 4) ; `shuffle` (Tâche 3)
- *Produit :*
```ts
/**
 * Choisit `count` symboles offerts parmi les plus fréquents, dont au moins une voyelle.
 * `count` est ramené dans [2, 3] puis borné par le nombre de symboles disponibles.
 */
export function pickGivens(
  counts: ReadonlyMap<Sym, number>,
  count: number,
  rng: () => number,
): Set<Sym>;
```

**Règle.** Le tirage se fait dans le tiers supérieur des symboles par fréquence — jamais uniformément
sur tout l'alphabet. Avec deux ou trois cadeaux seulement, tirer un `Ê` présent une fois reviendrait
à n'offrir rien.

```ts
import type { Sym } from './types';
import { isVowel } from './alphabet';
import { shuffle } from './rng';

export function pickGivens(
  counts: ReadonlyMap<Sym, number>,
  count: number,
  rng: () => number,
): Set<Sym> {
  const target = Math.min(Math.max(count, 2), 3, counts.size);

  // Symboles triés par fréquence décroissante.
  const ranked = [...counts.entries()]
    .sort((a, b) => b[1] - a[1] || a[0].localeCompare(b[0]))
    .map(([sym]) => sym);

  // Écarter les symboles à occurrence unique : offrir un « Ê » présent une fois n'apprend rien.
  // Repli sur l'ensemble si tout le texte est composé d'hapax (citation très courte).
  const frequents = ranked.filter((sym) => (counts.get(sym) ?? 0) > 1);
  const base = frequents.length >= target ? frequents : ranked;

  // Vivier : le tiers supérieur, jamais moins que la cible.
  const poolSize = Math.min(base.length, Math.max(target, Math.ceil(base.length / 3)));
  const pool = base.slice(0, poolSize);

  const vowels = pool.filter(isVowel);
  const chosen = new Set<Sym>();

  // Garantir une voyelle : la plus fréquente du vivier si aucune n'est disponible ailleurs.
  const vowelPool = vowels.length > 0 ? vowels : ranked.filter(isVowel);
  if (vowelPool.length > 0) {
    chosen.add(shuffle(vowelPool, rng)[0]);
  }

  for (const sym of shuffle(pool, rng)) {
    if (chosen.size >= target) break;
    chosen.add(sym);
  }

  return chosen;
}
```

```ts
// board.ts
import type { Sym, AccentMode, Cell } from './types';
import { toSymbols } from './alphabet';

export function buildBoard(
  text: string,
  mode: AccentMode,
  cipher: ReadonlyMap<Sym, number>,
  givens: ReadonlySet<Sym>,
): Cell[] {
  const chars = [...text];
  const symbols = toSymbols(text, mode);

  return symbols.map((sym, i) => {
    if (sym === null) return { kind: 'fixed', char: chars[i] };
    const given = givens.has(sym);
    return {
      kind: 'letter',
      code: cipher.get(sym)!,
      char: chars[i],
      filled: given ? sym : null,
      given,
    };
  });
}
```

```ts
import { shuffle } from './rng';

export function buildDeck(
  solution: readonly (Sym | null)[],
  givens: ReadonlySet<Sym>,
  rng: () => number,
): Sym[] {
  const cards = solution.filter((sym): sym is Sym => sym !== null && !givens.has(sym));
  return shuffle(cards, rng);
}
```

```ts
export interface Puzzle {
  quoteId: string; text: string; seed: string;
  accentMode: AccentMode; handCapacity: number; maxErrors: number;
  solution: readonly (Sym | null)[];
}

export interface GameState {
  puzzle: Puzzle;
  board: readonly Cell[];
  known: ReadonlyMap<number, Sym>;
  deck: readonly Sym[];
  hand: readonly Sym[];            // pile LIFO, le dernier est jouable
  selectedCell: number | null;
  errors: number;
  status: 'playing' | 'won' | 'lost';
}

export type Action =
  | { type: 'SELECT_CELL'; index: number }
  | { type: 'DRAW' }
  | { type: 'PLAY' }
  | { type: 'RESTART'; seed: string };

export interface GameOptions {
  seed: string; accentMode?: AccentMode;
  handCapacity?: number; maxErrors?: number; givenCount?: number;
}

export function createGame(quoteId: string, text: string, options: GameOptions): GameState;
export function reduce(state: GameState, action: Action): GameState;

/** Vrai si la carte du dessus peut être posée sur cette case sans risque connu. */
export function isPlayable(state: GameState, index: number): boolean;
export function topCard(state: GameState): Sym | null;
```

**Règles exactes à respecter :**
- `DRAW` refusé si pioche vide **ou** `hand.length >= handCapacity`.
- `PLAY` exige `selectedCell !== null` **et** `hand.length > 0`.
- Pose juste : case remplie, `known` mis à jour, carte retirée, sélection vidée.
- Pose fausse : `errors + 1`, sélection vidée, **la carte reste en main**.
- `errors === maxErrors` → `lost`. Plus aucune case `letter` vide → `won`.
- Toute action sur un état terminé est ignorée.
- L'état est **immuable** : chaque action retourne un nouvel objet.

**Tests exigés — chacun est une propriété de monotonie, pas une valeur figée.** Comparer deux textes

## Vérification de bout en bout

```bash
node -v                      # v24.x
npm test                     # tous les tests du domaine et des outils passent
npm run validate:quotes      # corpus conforme
npm run build                # build du portail
npm run build-storybook      # atelier construit
npm run storybook            # atelier consultable
```

**Contrôles manuels, après le build :**
1. Ouvrir le portail, le cryptogramme apparaît au catalogue.
2. Lancer une partie : 2 ou 3 correspondances déjà offertes, main vide, compteur à 0/3.
3. Piocher six fois : la main s'arrête à cinq cartes, le bouton se désactive.
4. Cliquer une carte sans case sélectionnée : rien ne se produit.
5. Sélectionner une case, poser juste : la case se remplit, la table de correspondance s'enrichit,
   la carte du dessous réapparaît.
6. Poser faux trois fois : la partie est perdue, la carte est restée en main à chaque erreur.
7. Rejouer : même citation, chiffrement différent.
8. Gagner : l'accentuation d'origine est restituée, l'auteur et la source s'affichent.
9. Couper le réseau, recharger : le jeu reste jouable.
