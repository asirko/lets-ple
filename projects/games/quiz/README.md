# Quiz géographie

Bibliothèque Angular chargée sous `/quiz`, moteur pur sous `src/lib/domain`,
façade signals sous `store`, composants avec showcases sous `ui`.

Voir [règles, données et architecture](../../../docs/reference/domain-quiz-geographie.md).

Vérifier avec `npm test -- quiz`, `npx ng test quiz --watch=false` et
`npm run build:quiz`. Le corpus local est versionné sous `content/geography`.
